Пояснения


                

                    
iss (Issuer)

                    

                        Сервис, который выпустил JWT-токен. Обычно это сервис аутентификации.
                        Получатель токена может проверить это поле, чтобы убедиться, что токен
                        выдан доверенным источником.
                    

                


                

                    
sub (Subject)

                    

                        Идентификатор пользователя внутри токена. Чаще всего это id пользователя
                        в системе или другой уникальный идентификатор.
                    

                


                

                    
aud (Audience)

                    

                        Получатель токена. Это сервис или группа сервисов, для которых предназначен
                        данный JWT. Сервис может проверить это поле, чтобы убедиться, что токен
                        предназначен именно для него.
                    

                


                

                    
exp (Expiration Time)

                    

                        Момент времени, когда токен перестаёт быть действительным. После этого
                        времени сервер должен отклонять запросы с таким токеном.
                    

                


                

                    
iat (Issued At)

                    

                        Момент времени, когда токен был создан. Используется для понимания возраста
                        токена и иногда для проверки его валидности.
                    

                


                

                    
roles

                    

                        Роли пользователя в системе, например USER или ADMIN. Эти данные используются
                        сервисами для проверки прав доступа и принятия решений об авторизации.
